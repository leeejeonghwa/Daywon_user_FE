# 💰 Daywon: LLM 기반 금융 학습 앱

## 📌 소개 (Introduction)

이 프로젝트는 **대규모 언어 모델(LLM)**을 활용하여 제작한  
**금융 교육용 학습 애플리케이션**입니다.  

앱은 LLM을 이용해 금융 학습에 필요한 **예시 프롬프트, 문제, 영상 자료** 등을 자동 생성하여  
사용자가 보다 효과적으로 금융 지식을 학습할 수 있도록 지원합니다.  

본 프로젝트는 **캡스톤 디자인**의 일환으로 개발되었습니다.
